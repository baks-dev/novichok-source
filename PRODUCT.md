# НОВИЧОК — первые 90 дней

## Выбор задачи
Для руководителей склада, магазинов, продаж и офиса компании на 400 сотрудников. Не потерять конкретный сигнал о трудностях нового сотрудника между задачей приёма в Битрикс24 и увольнением. Гипотеза: короткая обратная связь и персональная помощь полезнее ещё одного общего чек-листа.

## Основной сценарий
1. Новичок отвечает на три вопроса: понятны ли задачи, есть ли доступы/инструменты, есть ли человек для помощи. Отмечает самочувствие и может оставить комментарий.
2. Руководитель видит очередь первых 90 дней: сначала нерешённые препятствия, затем отсутствие обратной связи более 7 дней.
3. В карточке видит конкретный ответ и историю, назначает действие с ответственным и сроком.
4. Закрывает действие с обязательным результатом. Только новый ответ новичка снимает сигнал о препятствии; закрытие задачи само по себе его не скрывает.

## Границы
Все имена и события синтетические. Общий демостенд без авторизации, не предназначен для реальных персональных данных. SQLite хранит изменения на сервере. Режим новичка переключается в интерфейсе только для демонстрации; это не защищённый личный кабинет. Битрикс24: доступен текст задачи для ручного переноса, сетевой интеграции нет. Нет ML-оценки людей, рейтингов производительности и обещаний снизить текучесть. Эффект потребует пилота.

## Критерии приёмки
- Отправленный ответ сохраняется после перезапуска и сразу меняет очередь руководителя.
- Действие требует ответственного и срока, закрытие — описания результата.
- Повторный ответ не стирает историю. Действия и ответы сохраняются транзакционно SQLite.
- Есть поиск, фильтр подразделения, пустое состояние, ошибки загрузки и валидации.
- Дата и стаж рассчитываются относительно текущего дня, даты демоданных относительны первому запуску.
- Проверки: node:test для API, правил приоритета, валидации и сохранения; браузерный smoke test, если браузер доступен.

Макета нет: интерфейс разработан в рамках задания. Внешних сервисов и передачи данных нет.
